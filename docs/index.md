## 关于本站

- 本站是社区维护的**非官方**翻译，内容跟随 [NiceGUI 官方文档](https://nicegui.io/documentation)同步更新，以官方英文文档为准。

- 发现翻译错误或内容过时，欢迎到 [GitHub](https://github.com/Yuerchu/NiceGUI-docs) 提交 issue 或 PR。
